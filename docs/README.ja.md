# 会話フロート

**dsh-conversation-float** は、DSH の会話を DSH 内部の本物のフローティングウィンドウに変えます。二つ目の OS ウィンドウではありません。ウィンドウはアプリの上に浮かせておくことも、左サイドバーのタスクバー行として最小化することも、右サイドバーへドッキングすることもできます。プラグインのページや自動化のページ、その他の左サイドバーの項目を開いている間も、会話は使えるままです。

## 手に入るもの

- セッションのタイトルバー右端にある小さなウィンドウアイコンから**ワンクリック**。
- **本物の会話**であり、描き直した複製ではありません。入力、スクロール、Conversation/Trajectory タブ、コンポーザー、添付、ペルソナ選択はネイティブのまま動きます。
- セッションごとに一つずつ、**複数のフロート**。それぞれが左サイドバーに自分の行を持ちます。
- **ウィンドウを前面に出すだけのタスクバー**。セッションの行をクリックするとそのフロートが前面に出るだけで、背後のページは変わりません。
- **会話以外のページでも完全な会話**。Plugins、Automations、Settings、その他の左サイドバーの項目を開いても、ライブな会話のフロートはヘッダー、View タブ、コンポーザーを備えたまま画面に残ります。ページはフロートの背後、中央列に留まります。
- **三つの状態を持つ入口ボタン**。フロートを開く、DSH の残りを隠す、DSH の残りを戻す。
- **消えるべきときに消えるメニュー行**。ウィンドウが最小化されると「会話をここにしまう」が隠れ、右へドッキングされると「会話をここへ移動」が隠れます。

## 開く・最小化・閉じる

セッションのタイトルバーにあるウィンドウアイコンをクリックします。フロートは大きめ（約 920×720、ウィンドウに合わせて拡縮）に開き、DSH の残りは表示されたまま、両サイドバーは空いた場所に残ります。

同じボタンが三つの状態を順に切り替えます。

1. フロートを開く
2. DSH のインターフェースを隠し、フロートだけにする
3. DSH のインターフェースを再び表示する

フロートを閉じる、左サイドバーへ最小化する、右サイドバーへドッキングするのいずれでも、サイドバーはフロートを開いたときに記録した配置へ戻ります。スナップショットは一度だけ取り、ウィンドウが開いている間に上書きされることはありません。フロートを開いている間にサイドバーへ加えた変更は追跡されません。

ウィンドウの **—** ボタンで最小化します。ウィンドウは見えなくなりますが、左サイドバーのタスクバー行は残ります。その行をクリックすれば戻ります。**✕** ボタンは完全に閉じます。ウィンドウとその行が消え、会話は中央列へ戻ります。

DSH が隠れている間は、**Escape** でインターフェースが戻ります。

## 会話を移動する

ウィンドウのタイトルバーをつかんでドラッグします。**1.2 秒**そのまま押し続けるとドロップ帯が有効になり、タイトルバーが色づき、ポインタ下の帯に沿って枠が追従し、離した位置の帯へ会話が落ちます。押し続ける前に離しても何も起きません。タッチでは、押し続けが完了する前に 10 px を超えて動かすと、その操作は通常のウィンドウ移動のままになります。

| 落とし先 | 結果 |
| --- | --- |
| **左サイドバー** | ウィンドウは左サイドバーへ最小化されます。閉じるのではなく、タスクバー行が戻るための入口です。中央列は空いたままです。 |
| **中央** | ウィンドウが閉じ、会話は中央列へ戻ります。 |
| **右サイドバー** | 会話は右サイドバーのネイティブなページとしてドッキングし、DSH 自身の戻す・閉じる操作を備えます。 |

左サイドバーの行が持つのは会話のタイトルで、プラグイン名ではありません。ウィンドウが別の会話を表示している間も、そのタイトルは変わりません。行をクリックするとそのウィンドウを表示して前面に出すだけで、プラグインのメインパネルを選ぶことも、プラグインや自動化のページを奪うこともありません。

**ドラッグせずに済ませることもできます。** 左サイドバーの *More* メニューに **「会話をここにしまう」** が、右サイドバーのガイドに **「会話をここへ移動」** があります。会話がすでにその場所にあるときは、それぞれの行が自分から隠れます。

## 会話以外のページ

Plugins、Automations、Settings、その他の左サイドバーの項目を開くと、会話の列は中央列へ戻り、ページは通常の三列フレームを使えます。ライブな Session のフロートは画面に残り、**ローカルの完全な会話**へ切り替わります。セッションのヘッダー、Conversation/Trajectory タブ、コンポーザーを備えます。読み取り専用の記録ではありません。

ページは**フロートの背後**にあります。ページで作業するには、フロートを脇へドラッグしてください。Session のタスクバー行をクリックしてもフロートが前面に出るだけで、ページは開いたまま変わりません。ページを閉じるか、通常どおり会話へ戻ると、本物の会話の列がフロートへ戻ります。

**ライブではない** Session のウィンドウは、やはり読み取り専用の記録を表示します。一つの会話にライブなコンポーザーは一つだけで、コンポーザーと View タブはライブな Session のものです。

## 複数ウィンドウとタスクバー

各 Session はフロートを一つ持てます。すべてのフロートは左サイドバーに行を得て、タスクバーのように並びます。行の名前はそれぞれの Session 名です。

- 行をクリックすると**そのウィンドウが前面に出ます**。現在の Session は切り替わらず、メインパネルも変わりません。
- ライブでないウィンドウが最前面にあるときは **「この会話に切り替え」** チップが表示されます。クリックするとその Session がライブになり、ウィンドウが本物の会話の列を受け取ります。
- 一つのウィンドウを閉じても、ほかのウィンドウには影響しません。
- Session のタスクバー行は入口であり、会話の二つ目のライブコピーにはなりません。

## 右サイドバーへドッキングする

右へドラッグするか **「会話をここへ移動」** を使うと、タブは DSH の右サイドバーへ渡されます。タブ種別は `keepMounted` 付きで登録されるため、右サイドバーの別タブへ切り替えても会話は自分のタブ本文に残ります。その Session がライブである間は、列は画面に表示されている保持済みの本文に従います。それ以外の Session では、再び中央列が定位置になります。

## 下書きとコンポーザー

Session には入力シェルが一つ、エディタが一つだけあり、エディタは同時に一つの DOM ルートにしか載れません。会話が中央列、ウィンドウ、右サイドバーのページの間を移動するとき、プラグインは画面上のコンポーザーへエディタを付け直し、下書きの書き手を空のスロットへ戻します。表示されている下書きが、そのまま送信される下書きです。

フロートを閉じても、再マウントを強制するために別の View タブをクリックすることはもうありません。プラグインがエディタを直接修復するため、ウィンドウは Trajectory や他の View をちらつかせることなく会話へ戻ります。

## パフォーマンス

アニメーションフレームごとに行うレイアウト計測は最大 1 回です。三つのドロップ帯は押した時点で一度だけ計測します。DSH の変更反映を待つ処理はフレーム駆動で、プラグインは**インターバルを一切持たず**、DSH がすでに発生させるレイアウトパスで修復を行います。枠は帯が変わったときだけ描き直し、移動には `transform` を使います。

## 既知の制限

- フロートは **DSH ウィンドウの内側**にあり、独立した OS ウィンドウではありません。
- 会話のホストは常に**一つ**です。タスクバー行は入口であり、二つ目のライブコピーにはなりません。
- Session がライブでないウィンドウは**読み取り専用の記録**を表示し、View タブもコンポーザーもありません。入力するにはライブな Session へ切り替えてください。
- 会話以外のページを開いている間も、ライブなフロートはローカルの完全な会話を保ちますが、そのページは**ウィンドウの背後**にあります。フロートが自動でサイドバーへ縮んだり、自分をドッキングしたりすることはありません。
- フロートはそれを開いた Session に属します。Session を切り替えると、会話は新しい Session の中央列かその Session 自身のフロートへ渡り、戻ると以前のフロートが再び現れます。
- DSH を再起動するとフロートとタスクバー行は消え、会話は中央列へ戻ります。
- コンポーザーの修復は DSH 内部のいくつかの形（コンポーザーの箱の背後にあるエディタ、会話の入力シェル、その下書きスロット）に依存しています。将来の DSH リリースでそれらの名前が変わった場合、クラッシュせず以前の挙動へ劣化します。

## インストール

DSH **>= 0.2.2-rc.1** が必要です。

### npm から

    npm i dsh-conversation-float@0.3.0

次に **profile の `package.json`** へ登録します。両方の手順が必要です。

1. `dependencies` に `"dsh-conversation-float": "^0.3.0"` を追加する
2. profile の `dsh.profile.bundles` リストに `"dsh-conversation-float"` を追加する

登録されたバンドルだけがプラグイン一覧に現れ、切り替えられます。

### tarball から

    dsh plugin add <path-to>/dsh-conversation-float-0.3.0.tgz

あるいは tarball を profile に置いて `file:` 依存として指定し、その名前をバンドルリストへ追加します。

### ソースから

1. ソースを任意の場所に置く
2. `<profile>/node_modules/dsh-conversation-float` へリンクする
3. profile に `link:` 依存とバンドル名を追加する

バンドルは起動時に組み立てられるため、インストールやアップグレードのあとは DSH を再起動してください。
