# Плавающее окно беседы

**dsh-conversation-float** — вынимает **вид беседы** из его фиксированного места в DSH и превращает в плавающую панель.

Окно — **собственное окно DSH**, плавающая панель того же док-кита, что использует правая боковая панель, а не второе окно браузера: на панели задач по-прежнему одно окно DSH. Внутри — **настоящий вид беседы**, та же колонка, а не перерисованная копия, поэтому ввод, прокрутка, переключение «Беседа / Траектория», композер, вложения и выбор персонажа остаются нативными.

## Как пользоваться

**Вход**: маленький значок окна справа в строке заголовка сессии (*Conversation float*).

Одно нажатие открывает окно, **и остальной DSH остаётся на экране**: обе боковые панели раскрыты, окно стоит по центру свободного места. То же нажатие затем скрывает интерфейс DSH, оставляя только окно — подсказка меняется с *Скрыть DSH* на *Показать DSH* — а следующее нажатие возвращает интерфейс. Закрытие окна, уборка в левую панель или пристыковка справа сами возвращают боковые панели на место.

Окно **открывается крупным** (около 920×711, под размер окна), вызывая собственное намерение док-кита `resizeFloat` — `sidebarRight.require()` → `actions.resizeFloat(sessionId, paneId, rect)`, где `paneId` берётся из `data-dockkit-float` у окна. Оно только увеличивает: уже расширенное окно никогда не сжимается назад.

Свёрнутая правая панель **раскрывается до** открытия окна, чтобы «вернуть в панель» было куда лечь; свёрнутая левая — тоже. Свёрнутость определяется по ширине, поэтому узкое окно никогда не получает записанный флаг свёрнутости.

**Закрытие окна — или выход из скрытого состояния — возвращает боковые панели к тому виду, который был у окна.** Если при открытом окне ты **сам** закрыл или открыл панель, возвращается именно последняя раскладка, в том числе при закрытии из скрытого состояния: окно, сведённое к правой колонке, таким и остаётся. «Сам» считается только твоё нажатие на панель или клавиша, в обе стороны; то, что DSH сворачивает левую панель в узком окне, скрытая панель перестраивается или нажатие внутри самого окна — не считается. Снимок прежнего вида делается один раз, до касания любой панели, и никогда не перезаписывается, пока окно открыто.

## Перетаскивание влево, в центр или вправо

Удерживай строку заголовка окна и тяни. **Удержание 1,2 с** переводит перетаскивание в режим оценки; с этого момента контур следует за полосой под указателем, и отпускание опускает окно в эту полосу. Оценка начинается один раз за перетаскивание, поэтому смена полосы больше не ждёт. Отпускание раньше 1,2 с ничего не делает — случайных перемещений нет.

Три полосы — это настоящие колонки окна: **левая панель** (колонка 0 рамы, сейчас 0..280), **средняя колонка** (280..680), **правая панель** (`data-rightbar-col`, 680..1097). Контур покрывает ровно тот блок, куда ляжет окно, того же размера.

| Куда | После отпускания |
| --- | --- |
| **Влево** | Окно **убирается в ящик левой панели**: оно не закрыто, а невидимо, поэтому средняя колонка остаётся пустой; в левой панели появляется строка **с именем этой беседы**, которая его возвращает |
| **В центр** | Окно закрывается, беседа возвращается в среднюю колонку |
| **Вправо** | Беседа пристыковывается как **страница правой панели** — нативная вкладка DSH со своей *Вернуть в панель* и закрытием |

Строка в левой панели появляется только после того, как окно действительно туда положили; до этого левая панель пуста и постоянного входа нет. Строка несёт заголовок убранной беседы — не имя плагина — и смена беседы этот заголовок не меняет: нажатие возвращает *ту* беседу и снова показывает её окно.

**Или без перетаскивания.** В меню *Ещё* левой панели есть **Убрать беседу сюда**, а в карточке *Другие инструменты* правой панели — **Переместить беседу сюда**. Оба — обычные строки меню DSH под штатными, и каждая прячется, когда беседа уже там, куда она её отправила бы.

## Как это устроено (и почему беседа не перерисовывается)

- Беседа существует как **один DOM**: плагин переносит колонку, которая её несёт, в тело панели (тот же документ, тот же корень React) и возвращает при закрытии или смене хозяина; если её прежнее место исчезло, запасной вариант — средняя колонка.
- **Убрать влево** = метка на корне окна делает его невидимым (`visibility`/`opacity`); панель **не закрывается**, поэтому средняя колонка может оставаться пустой.
- **Пристыковать вправо** = передаёт вкладку правой панели (`openResource(..., { destination: 'sidebar' })`), а перенос и стыковку делает DSH.
- **Пристыкованная вкладка сохраняет тело**: тип вкладки регистрируется с `keepMounted`, поэтому при переходе на другую вкладку правой панели беседа остаётся в этом теле, а не возвращается в среднюю колонку. Колонка следует за тем удержанным телом, что на экране, пока её собственная сессия текущая; для любой другой сессии средняя колонка снова место, как и раньше.

## Производительность

Каждый кадр анимации делает не больше одного измерения; три полосы измеряются один раз, при нажатии. Контур перерисовывается только когда полоса действительно меняется, и движется через `transform`. Ранние версии измеряли раскладку и писали четыре стиля на каждое движение мыши — именно это, а не логика сброса, делало перетаскивание тяжелее, чем у DSH.

## Известные ограничения

- У беседы ровно один хозяин: строка в левой панели — это **вход**, а не вторая живая копия беседы.
- Окно принадлежит сессии, которая его открыла: при переходе в другую сессию беседа возвращается в её среднюю колонку (или в её собственное окно, если оно есть), а при возврате окно этой сессии появляется снова.
- Строка в левой панели носит имя убранной беседы и сохраняет его, пока окно смотрит на другие беседы. Нажатие переключает на эту беседу и показывает её окно; оно никогда не открывает окно той беседы, что сейчас на экране.
- Ящик держит **одну** беседу. Уборка другой заменяет жильца: замещённое окно снова становится обычным окном (теряет только метку ящика), поэтому вторая строка в левой панели не появляется.
- Достать окно из ящика — значит вернуть его **туда, где его убрали** (возможно, поверх левой панели); оно не центрируется заново.
- Это окно внутри окна DSH, а не отдельное системное окно.
- После перезапуска DSH состояние ящика пропадает; беседа возвращается в среднюю колонку.

## Перемещение окна

Окно перемещает собственное перетаскивание DSH. Пока рука на панели, плагин не применяет своё место — повторное применение запомненного прямоугольника посреди перетаскивания и было причиной того, что раньше окно отскакивало при первом движении.

## Установка

Нужен DSH **>= 0.2.2-rc.1** — версия, под которую этот пакет разрабатывается и проверяется.

### Из npm

```bash
npm i dsh-conversation-float
```

Затем зарегистрируй в **`package.json` профиля** — нужны оба шага:

1. добавь `"dsh-conversation-float": "^0.1.4"` в `dependencies`
2. добавь `"dsh-conversation-float"` в `dsh.profile.bundles` — только зарегистрированный пакет появляется в списке плагинов и может включаться

### Из исходников

1. положи исходники куда угодно
2. свяжи их junction'ом в `<профиль>/node_modules/dsh-conversation-float`
3. в `package.json` профиля: в `dependencies` — `"dsh-conversation-float": "link:<путь>"`, в `dsh.profile.bundles` — `"dsh-conversation-float"`
4. `client.js` перезагружается на лету; хост-половина (`index.js`) — пустая заглушка, перезапуск нужен только если её менять
